Privacy Policy

Last updated: October 30, 2026

Discordance File Uploader ("the app") is a private tool used only by the owner of the Discordance File channel to upload the owner's own videos to the owner's own TikTok account.

Data we use

When the owner signs in with TikTok, the app receives an access token and basic account information (such as the display name) for that one account. It uses them only to upload and publish the owner's videos.

Storage

The access token is stored only on the owner's own computer. It is not sold, shared, or sent to any third party other than TikTok's own API.

Other people's data

The app does not collect, read, or store data about any other TikTok users or viewers.

Deleting data

Access can be removed at any time in TikTok's settings (Security → Manage app permissions); the stored token is then deleted from the computer.

Contact

Questions can be sent through the Discordance File YouTube channel.
